# Vivid Acrylic Marker Photo Skill

将用户上传的日常静物或风景照片，转换为适合小红书发布的 3:4 竖版丙烯马克笔色块插画。

它的目标不是把照片变成泛化的“手绘风景”，而是在保留原图主体、构图、比例、透视、空间关系和主色彩关系的前提下，把摄影质感转换成不透明、手绘、无描边的色块语言。

## 风格特点

- 大面积、边界明确的不透明丙烯色块
- 通过相邻色块的色相和明度对比塑造体积
- 保留原照片的关键主体与空间结构
- 将树叶、草地、岩石、云层等细节合并成有节奏的形状
- 轻微的手绘边缘与纸张肌理
- 默认 3:4 竖版，适合小红书图文发布

### 无描边规则

这是本 Skill 最重要的视觉约束：

- 不使用黑色、深蓝色或深褐色勾勒物体轮廓
- 不使用线稿、统一描边、白色光晕或贴纸边框
- 深色只能作为内部阴影色块，不能沿轮廓走线
- 每个边界都应由相邻的不透明色块自然形成

## 安装

### Codex 桌面版

将仓库中的 Skill 文件夹安装到个人 Skills 目录：

```bash
gh repo clone mengfanfreyachan/vivid-acrylic-marker-photo-skill
```

然后将该文件夹放入：

```text
~/.codex/skills/
```

重启 Codex 后即可使用。

### 从当前仓库安装

也可以使用 Codex 的 Skill 安装器，从 GitHub 仓库路径安装：

```text
$skill-installer https://github.com/mengfanfreyachan/vivid-acrylic-marker-photo-skill
```

## 使用方法

上传一张日常静物或风景照片，并在提示词中明确调用：

```text
$vivid-acrylic-marker-photo-skill

把这张照片转换成丙烯马克笔色块插画，保留原图构图和颜色关系。
```

也可以直接描述需求，让 Skill 根据匹配条件自动触发：

```text
请把这张山谷照片画成无描边的丙烯马克笔色块插画，输出 3:4 小红书尺寸。
```

## 输入建议

适合：

- 山谷、海边、街景、建筑、植物等风景照片
- 桌面静物、食物、器物、书籍、花卉等日常照片
- 有明确主体、颜色关系和空间结构的照片

为了获得更稳定的结果，建议使用：

- 主体清晰、没有严重运动模糊的照片
- 至少能辨认主要形状和色彩的照片
- 需要保留的文字、商标或人脸尽量提前说明

## 生成流程

Skill 会先分析照片中的主体、空间锚点、主色和主要形状，然后生成一条针对该照片的编辑提示词。生成后会检查：

1. 原照片主体是否仍然可识别；
2. 山脊、桌面、溪流、器物等关键空间关系是否保持；
3. 色块是否足够大、足够不透明；
4. 是否错误出现了勾线、渐变或写实纹理；
5. 是否适合 3:4 竖版发布。

如出现明确问题，Skill 会只针对该问题进行一次定向修正。

## 不适合的结果

本 Skill 会主动避免：

- 写实照片滤镜
- 柔和渐变和空气透视
- 油画厚涂或水彩晕染
- 黑色线稿、深色勾边和白色描边
- 凭空增加建筑、人物、动物或装饰物
- 文字、水印、Logo 和广告式排版
